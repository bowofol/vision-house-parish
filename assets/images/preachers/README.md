# Preacher photographs

Put photographs of the actual preachers here. Use JPG, PNG, WebP or AVIF with simple filenames. A portrait crop with the face near the upper centre works well in the circular frame.

Set each sermon's `preacherPhoto` in `js/data/sermons.js` to its own path, starting with `assets/images/preachers/`. There is no default pastor photograph. See `assets/videos/sermons/README.md` for the complete workflow.

Pastor Dele Oyedeiran's approved portrait is available at `assets/images/preachers/pastor-dele-oyedeiran.jpg`, copied from `img/New folder/WhatsApp Image 2026-10-07 at 9.45.10 PM.jpeg`.

For a confirmed sermon preached by him, set `preacher: 'Pastor Dele Oyedeiran'` and `preacherPhoto: 'assets/images/preachers/pastor-dele-oyedeiran.jpg'` in its data entry. These are documentation values only; no sermon is published automatically.
