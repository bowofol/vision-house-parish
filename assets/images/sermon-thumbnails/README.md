# Sermon thumbnails

Put your real sermon thumbnail images here. Use a landscape 16:9 image, ideally at least 1280 x 720 pixels, in JPG, PNG, WebP or AVIF format. Choose a frame where faces and important text remain visible.

Set `thumbnail` in `js/data/sermons.js` to the exact path starting with `assets/images/sermon-thumbnails/`. These are also used as the local video's poster image. See `assets/videos/sermons/README.md` for instructions.
