The official logo is rccg-logo.png. Pastor Dele Oyediran's approved portrait is pastor-dele.jpg. Keep both identities intact.

See REDESIGN-NOTES.md at the project root for the exact photograph-to-section mapping. See CONTENT-GUIDE.md for replacements, alt text, gallery markup and video setup. Do not identify an unconfirmed person as the pastor or assign a photograph to an unconfirmed programme.
